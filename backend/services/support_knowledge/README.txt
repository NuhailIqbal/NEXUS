The NEXUS in-product assistant's knowledge base (loaded by services/support_assistant.py).

Plain text files, joined in file-name order into the assistant's system prompt. Edit them like documents: when a feature,
price or menu name changes, change the matching line here. Keep it factual, in the words a customer sees on screen, and keep
the "what NEXUS can't do yet" list honest (the assistant repeats it). Every extra 1,000 characters costs about 250 more
input tokens per chat reply, so prefer short exact lines over long prose.

Sources: written on 2026-10-27 from the code (pages, routers, services), not from the marketing site. Re-check against the
code after big releases.
