PART 2 - CONTACTS, CONVERSATIONS, ANALYTICS, REPORTS, CALL EVENTS, CALLBACKS, AUTOMATION, INTEGRATIONS

DATABASE > CONTACTS (menu: Database > Contacts; buttons "Import CSV" and "Add Contact")
- The table shows Name, Phone, Email, List, Status, Created and row actions View, Settings (edit) and Delete (Owner only, no confirmation). Each column sorts and filters; page sizes 10, 25, 50, 100.
- Add Contact: a 2-step form (Basic Info, Review) then "Create". Name and Phone are required; Email is optional; List is optional ("No list (unassigned)" or an existing list). New contacts are Active.
- Import CSV: click "Import CSV", optionally choose "Add to List (optional)" (an existing list, or "+ Create new list..." and type its name), then "Choose CSV File". The first row must be headers, for example name,phone,email. Phone is required: rows without a phone are skipped and the message says how many. The name comes from a column called name, full_name or first_name (if there is none the contact is called "Imported"). Email is optional. Column order and capital letters in headers do not matter. Do not put commas inside a value (the file is read as a plain comma-separated file, so quoted commas break a row). Only .csv files work: in Excel use Save As > CSV (Comma delimited). There is no duplicate check, so importing the same file twice creates the contacts twice. There is no row limit set by NEXUS.
- Contact Status (Active, Inactive, Pending) is only a label: it does NOT stop a contact from being called. There is no per-contact Do-Not-Call flag. To keep a person from being called, delete them or remove them from the list, or use DNC screening (see Integrations).
- Known issue: choosing "No list" when editing a contact does not remove it from its list. To take contacts out of a list, delete the contact or the list.

DATABASE > LISTS (menu: Database > Lists; button "New List")
- A list groups contacts so a campaign can call them. Each card shows the name, created date and live contact count; actions are View, Rename and Delete. Deleting a list keeps its contacts (they become unassigned) but any campaign that used the list loses it, so assign another list.

ALL CONVERSATIONS (menu: All Conversations)
- Every call (inbound and outbound) appears automatically a short time after it ends; the recording and transcript can lag a minute or more. There is no manual sync button. The table refreshes itself every 30 seconds. Only phone calls are recorded (not SMS, WhatsApp or web chat).
- Top cards (all time): Total, Completed, Failed, In Progress, Qualified, Inbound, Outbound. Columns: Channel, Agent, Contact (the saved contact's name if the number matches, otherwise the number), Phone, Duration (m:ss), Status, Type (Inbound or Outbound), Qualified, Outcome, Time. Filters: text boxes for channel, agent, contact, phone, duration and outcome; dropdowns for Status, Type and Qualified; a one-day Date picker.
- Status: Completed is a normal end; Failed is a call error; "No Answer" covers not answered, busy and voicemail. The Status dropdown's "Unsuccessful" option never matches anything.
- "Qualified" means the AI transferred or forwarded the call to a human. There is no separate "conversion" figure. Outcome is the last Call Event the agent raised during the call.
- The eye icon opens the call: an audio player, phone, duration, type, status, whether it was qualified, the outcome, "Transferred to", the "Call Events" the agent raised, an automatic "AI Summary" written from the transcript, and the full "Transcript" (click a line to jump the audio to it).

ANALYTICS (menu: Analytics > Channel, Campaign, Scenario)
- All three pages show: Total calls, Completed calls, Qualified calls, Active agents, Total campaigns, and a "Trends (last 14 days)" chart. Channel adds a bar chart per channel; Campaign adds a table (Name, Status, Contacts, Completed, Qualified, Progress); Scenario adds a table per agent. These pages are all-time with no filters or export. For filters and CSV export use Reports.

DASHBOARD HOME (menu: Dashboard)
- Date selector: Today (default), 7 days, 30 days, Custom (From/To, at most 366 days, not in the future). Weeks start on Sunday; the page uses your browser's time zone and refreshes every minute.
- Live strip (refreshes about every 10 seconds, independent of the range): Calls running now, Calls today (and how many were answered), Agents (and active), Outbound campaigns (and running), Inbound receptionists (and active).
- Six tiles, each compared with the equally long period before: Calls made; Answered rate (calls where a person picked up and talked, out of finished calls); Qualified leads (calls the AI handed to a person); Talk time; Spend (what the calls cost your account, phone-number rent not included); Cost per qualified lead (spend divided by qualified leads, a dash if there are none).
- Also a calls and qualified leads chart, a funnel (Calls made, Answered, Leads, Qualified), top-5 tables of campaigns, agents and receptionists, a "Needs attention" box when a campaign is stalled or has call errors, and a first-steps checklist for new accounts.

REPORTS (menu: Reports > Overview, Campaign, Vertical, State, Hourly Heatmap, Inbound & Outbound, Weekly & Monthly, Cost per Lead)
- Click "Filter" to choose a date range (Today, Yesterday, Last 7 days, Last 30 days, This month, Last month, Custom; at most 366 days), Campaign (multi-select), Vertical, Agent, Direction and Outcome, then "Search". "Clear" resets to ALL TIME. Most tables have "Export CSV". With no data the export says "There is no data to export for these filters."
- Definitions: only FINISHED calls count (Completed, Failed or No Answer). Consumed = a person picked up and talked. Dropped = every other finished call, with exactly one reason in this order: Blocked, Voicemail, Busy, No answer, Failed, or "Hung up at once" (the person ended it in under 3 seconds). Consumption % = consumed divided by total; Drop rate = dropped divided by total. Vertical = the calling agent's industry. State = the US state of the contact's area code (an estimate; non-US or ported numbers show as Unknown). Spend = the billed cost of the calls.
- Overview ("Call Consumption"): totals with change versus the previous period, an inbound vs outbound strip, a month > week > day summary, rule-based "Insights" and "Hotspots" (worst and best hour, state, vertical and campaign; groups under 5 calls are ignored). Campaign, Vertical and State pages break the same numbers down and show why calls were dropped; clicking a campaign opens its detailed reasons. Hourly Heatmap shows drop rate by weekday and hour and the highest-risk window. "Inbound & Outbound" has an Outbound tab (by campaign) and an Inbound tab (by phone number). "Weekly & Monthly" has weekly (Sunday to Saturday) and monthly tabs with presets.
- Cost per Lead: tabs Outbound and Inbound plus a "Lead values" button. Qualified lead = a call handed to a person. Lead = a qualified call, OR a call where the person asked for a callback, OR a call where the agent booked a meeting (counted per call). Cost per lead = spend divided by leads; cost per qualified lead = spend divided by qualified leads; both show a dash when there are none. Revenue and ROI appear only after you set lead values: Revenue = qualified leads x value per qualified lead + other leads x value per other lead; Profit = revenue minus spend; ROI % = profit divided by spend x 100.
- Set lead values (Owner only): Reports > Cost per Lead > "Lead values" ("What is a lead worth?"). Fill "Qualified lead (handed to a person)" and optionally "Other lead (callback or booked meeting)" under "All campaigns", optionally override per campaign (empty = use the account value), then Save. A campaign with leads but no value counts as $0 revenue.

CALL EVENTS (menu: Call Events, tab "Events")
- An event is a moment an agent reports during a call (for example "Callback requested" or "Interested"). Create it once in the library, then attach it to agents (agent wizard, step "Call Events"). Button "New Event". The form has: Event name (up to 60 characters), Outcome value (up to 60, defaults to the name, shown on the call when this is the last event), "When should the agent raise it?" (up to 200 characters; this is the instruction the AI follows), "Applies to" (Inbound & outbound, Inbound only, Outbound only) and the checkbox "Schedule a callback when this happens".
- Limits: 100 events in the library, 20 per agent; names must be unique. Editing or deleting an event updates every agent that uses it (if updating an agent fails you are told to open that agent and save again). Past calls keep their events.
- During a call the agent silently reports an event the moment it happens. At hang-up the LAST event becomes the call's Outcome. Events show in the call's detail and can be used as conditions in Automation (fields call_outcome and call_events).

CALLBACKS (menu: Call Events > tab "Callbacks")
- When an agent raises an event that has "Schedule a callback" on and the caller says something like "call me back at 5", NEXUS saves a real callback time (in the caller's own local time; at least 5 minutes ahead; if the time already passed today it moves to tomorrow; a newer request from the same number replaces the older one; with no time given it uses the next calling day at the default time).
- The Callbacks tab lists them: Customer, Agent, "Call back at", Status (Scheduled, Called, Failed, Skipped, Cancelled), "What they said". Actions: "Reschedule", "Mark called", "Cancel" (only for Scheduled). "Overdue - call them" shows when automatic calling is off and the time has passed.
- Settings button (Owner only): "Place callbacks automatically" is OFF by default: while off, callbacks are only recorded here and your team makes the calls. When on (a confirmation appears), due callbacks are placed by the agent within about a minute, only inside the calling days and hours you set (defaults Mon-Fri 09:00-18:00, default time 10:00, retry after 30 minutes, 2 attempts), never to do-not-call numbers, and the calls use your balance. A callback is skipped if no phone number is known, and not placed if the balance is empty or the account is on trial.

AUTOMATION (menu: Automation; button "Create New Flow")
- A flow is a visual workflow: drag blocks from the palette and connect them; double-click a block to edit it. It auto-saves every 30 seconds and keeps the last 10 versions. The list shows Name, Status, Modified with pause/resume, edit and delete (delete has no confirmation). Only Active flows run by themselves.
- Triggers: "Now" (start it yourself with the "Run now" button) and "Call Ended" (runs after every inbound or outbound call is logged, which can take up to about 90 seconds). Logic: Split (branches run together), Delay (minutes, hours or days; longer delays are saved and resume on time even after a restart), Condition (field status, qualified, call_outcome or call_events; operators equals, not equals, contains, greater than, less than; Yes/No outputs).
- Actions: Webhook (URL and method; sends the conversation id, phone and contact name), "Call Fixed Number" (an agent calls a number you type), "Call Back Contact" (an agent calls the number that triggered the flow), SMS, Email, "Update Contact" (set Status, Name or Email of the matching saved contact). Messages can use {{contact_name}}, {{phone}}, {{status}}, {{duration}}, {{call_outcome}} and {{call_events}}. Call actions check the account, balance, that the number is not already on a call, and DNC; a failed check is logged and skipped.
- To test: use a "Now" trigger and click "Run now"; results are in the "Runs" tab (Running, Success, Failed with the error). A "Run now" has no caller, so "Call Back Contact", SMS without a To number, and Email have nobody to use. Email nodes in "Call Ended" flows may have no recipient and be skipped. Needs an email integration (Brevo, SendGrid or SMTP) for email actions.

INTEGRATIONS (menu: Integrations; button "Add Integration")
- Offered: WhitelistData (do-not-call screening), Google Calendar, Twilio, Vonage, Telnyx (your own carrier), Brevo, SendGrid and SMTP (email). Other services (Slack, Zapier, HubSpot, Salesforce, generic webhooks and so on) are NOT offered.
- Each tile has "Test connection" (a live check that stores nothing; shows "Connection healthy" or the reason: "Authentication failed - credentials rejected.", "Timed out", "Missing ..."), Settings and Delete (Owner only, no confirmation). The Status can be Active or Inactive. Safest way to change credentials: delete and add the integration again.
- WhitelistData: "API Key", "Function Code" and "Secret" (or paste the full API URL) from whitelistdata.com. Once Active, outbound numbers are screened before dialing and the result is remembered for 30 days; if the service is unreachable the call is NOT placed. Campaigns have their own DNC screening switch (on by default).
- Brevo: API Key and From Email (a verified sender). SendGrid: API Key and From Email (a verified sender). SMTP: SMTP Host, Port (usually 587), Username, Password, From Email; only STARTTLS (port 587) works, not port 465 SSL. Emails sent by agents and automations go through your Active email integration; without one: "No email integration configured. Go to Integrations and add a Brevo, SendGrid or SMTP integration."
- Twilio, Vonage, Telnyx here are your own carrier accounts for phone numbers (see Phone Numbers).
- Google Calendar (only the Owner can connect, change settings or disconnect): Add Integration > Google Calendar > "Connect with Google" and approve. Fix "Needs to be reconnected" with "Reconnect". If it says "One-time setup needed first" or "Google Calendar isn't set up on this server yet", NEXUS support must finish setup. Calendar settings: timezone, working days (default Mon-Fri), day start 09:00 and end 17:00, meeting length 30 minutes (10-240), buffer 0-120 minutes, minimum notice 2 hours, booking window 30 days (1-90). With a calendar connected, an agent can check free times and book meetings (it creates a Google Calendar event and emails an invite if the caller gave an email). IMPORTANT: attaching the "Check Availability" and "Book Calendar Slot" tools to an agent is not possible from the dashboard agent form right now, so do not promise that booking works until support confirms it is enabled for the account.
- Not working or missing from the UI: the agent "Send SMS" and "Webhook Trigger" tools have no screen to set up; use the Automation SMS and Webhook blocks instead.
