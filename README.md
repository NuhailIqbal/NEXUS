# NEXUS — VAPI AI Missed-Call Follow-Up

AI calling workflow to identify missed calls from integrated database records and initiate automated callbacks using VAPI.

This is the Nexus project from my resume: an AI agent / automation system for lead handling and follow-up, built with VAPI voice agents, Supabase, and a FastAPI backend.

## What it does

- Identifies missed calls from integrated database records
- Initiates automated callbacks using VAPI
- AI agents and automation flows for lead handling and customer follow-up
- Dashboard for managing agents, contacts, lists, phone numbers, conversations, and automation flows
- Public marketing site plus an authenticated dashboard

## Stack

- **Frontend:** React 18 + TypeScript + Vite, Tailwind CSS + shadcn/ui, React Router v6, TanStack Query v5
- **Voice:** Vapi AI
- **Backend:** Python / FastAPI, PostgreSQL
- **Data & Auth:** Supabase (auth + database)
- **Other:** Recharts, React Flow, Stripe billing

See `CLAUDE.md` for commands and architecture, and `docs/` for more detail.
